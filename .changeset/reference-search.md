References get their own search in the row instead of the Studio's reference input: focusing it opens a popover listing the documents the reference can point to, narrowed down as you type. A picked reference now sits in the row like any other item, with the document's preview and status, and clicking it or its pencil searches for a replacement. The **Add item** type menu is now as wide as its items and centered under the button.
